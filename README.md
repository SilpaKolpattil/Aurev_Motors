# Aurev Motors — Car Showroom Website

A responsive React portfolio project for a premium car showroom. Built with React, JavaScript, HTML and CSS (no Tailwind setup required).

## Features

- Premium landing page and responsive navigation
- Vehicle catalog with category filters, search, and price sorting
- Individual vehicle detail pages
- Interactive configurator with exterior colours, trim, wheels, interior and live price estimate
- Test-drive booking modal with form validation and success state
- Responsive layouts for desktop, tablet and mobile
- Reusable React components and centralized vehicle data
- Accessible labels, focus states, and reduced-motion support

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

To create a production build:

```bash
npm run build
npm run preview
```

## Notes

- Vehicle names, specifications, prices, showroom location and imagery are illustrative demo content.
- Booking submissions are validated in the browser and display a confirmation state; they are not sent to a backend.
- For a production deployment, connect the booking form to a backend/API, store secrets server-side, add server-side validation, and replace illustrative vehicle specifications with verified data.
